# Topic-specific Guidance and References

English (canonical) | [简体中文](README.zh-CN.md)

Store guidance, examples, and sources that do not need to be loaded for every task.

- [Orchestration reference](orchestration.md): task briefs, reporting and replacement handoffs, capability boundaries, and cost evaluation. Read when complex delegation or handoff requires it; simple tasks do not need this reference.

For each new entry, identify its topic, path, and applicable scenarios. Each document should describe when it applies, its guidance, exceptions, evidence or sources, and the verification date for tool-related claims.

A proposal does not become a universal requirement merely by appearing here. Promote mature rules into the root AGENTS.md only when justified.
