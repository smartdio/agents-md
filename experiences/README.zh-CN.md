# 实践经验

简体中文译版 · [English（主版本）](README.md)。内容以英文主版本为准。

记录真实任务中的有效做法、失败案例和待验证假设。初始规范来自讨论，不代表已验证节省 token。

- [协作规范多 Agent 审查与桌面预演](2026-09-14-orchestration-review.md)：真实文档协作中的独立分析、场景预演、修改及复验记录；不属于运行故障实测或 token 基准。记录中的哈希和行号对应历史中文版本，不是后来的英文译版。

有实际经验时再创建记录，建议文件名为 `YYYY-MM-DD-主题.md`，并在本页补充索引。

## 轻量记录模板

```text
日期与场景：
问题：
采取的做法：
观察结果与证据：
适用边界／反例：
拟议规则：
状态：待验证／已采纳／不采纳／已失效
```

没有测量就不填写虚构数字；避免记录密钥、敏感原始数据和无关完整对话。
