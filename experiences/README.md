# Practical Experience

English (canonical index) | [简体中文](README.zh-CN.md)

Record effective practices, failures, and hypotheses from real tasks. The initial policy came from discussion, not demonstrated token savings.

- [Multi-agent review and tabletop rehearsal](2026-09-14-orchestration-review.md) (Chinese): independent analysis, scenario rehearsal, editing, and retesting during actual document collaboration. This is not a runtime fault test or token benchmark. Its hashes and line references identify the historical Chinese version, not the later English translation.

Create a record when there is actual experience to capture, using a name such as `YYYY-MM-DD-topic.md`, and add it to this index.

## Lightweight record template

```text
Date and context:
Problem:
Approach:
Observed results and evidence:
Applicable boundaries / counterexamples:
Proposed rule:
Status: unvalidated / adopted / rejected / obsolete
```

Do not invent measurements. Exclude credentials, sensitive raw data, and unrelated full conversations.
