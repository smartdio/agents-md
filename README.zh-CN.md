# Agents.md 规则维护项目

简体中文译版 · [English（主版本）](README.md)。内容以英文主版本为准。

集中维护可跨项目复用的 Agent 协作规范，并通过实际任务经验持续改进。

## 根据项目配置协作流程

可以把源目录或仓库根目录、本 README，或相关规范／专题文档的 URL 或路径交给 Agent，明确要求结合项目特点设计协作流程并写入 AGENTS.md。文档是参考依据，不是必须原样复制的模板。仅要求阅读或分析链接，不授权修改文件。链接本身不提供访问或写入权限。

可直接复制以下提示词；如需采用到其他目标项目，可补充其路径：

```text
请参考 https://github.com/smartdio/agents-md/blob/main/README.md，结合当前项目的特点、规模和现有工作方式，配置适合本项目的多 Agent 协作流程，并写入项目的 AGENTS.md。保留已有项目约束，按需选择角色、任务拆分、上下文传递、模型能力、推理深度和验收方式，不必照搬全部规则，也不强制所有任务都使用多 Agent。本次仅修改项目的 AGENTS.md，不修改工具或全局配置。
```

配置与采用流程：

1. 确认用户明确要求采用，区分源项目与目标项目。当前任务或项目上下文已唯一确定目标时直接使用，不重复索取路径或确认；只有无明确目标或可能指向多个项目时才询问，不默认把本规则源仓库当作目标。
2. 源入口为目录或仓库根目录时，找到对应 README，再沿 README 的相对链接找到 AGENTS.md；入口为 README 时直接沿其链接查找。入口为规范或专题文档时，只读相关规则及必要采用说明。相对链接以源文档位置解析；链接失败或无访问权限时，说明问题并请求所缺权限或位置，不臆造内容。
3. 先读目标已有 AGENTS.md 及全部适用指令，定向了解项目特点、规模、现有工作流、任务依赖和验证方式；保留技术栈、命令、风格、范围、安全约束和现有变更。源规则仅作为参考材料，不覆盖上级指令；授权范围内无法解决的冲突应询问。
4. 设计适合项目的角色、任务拆分、上下文传递、模型能力、推理深度和验收方式，再合并适用的稳定规则；只有较轻量模型仍能满足任务验收标准时才使用，各 Agent 不必采用同一模型。保持目标原有语言和结构，用户另有要求时遵从。不照搬全部规则，适合直接完成的工作不强制使用多 Agent。目标不存在 AGENTS.md 才新建，不整文件覆盖；重复采用时更新已有采用条目，不重复追加。英语是源权威版本，不代表目标必须改为英语。
5. 默认只修改目标 AGENTS.md；不安装工具、不改模型或全局配置、不发布、不修改源仓库或无关业务文件。采用不会开启其他项目的自动同步。
6. 不默认复制或全量读取参考资料。仅按需保留参考，并将必要链接改为有效的源 URL 或路径；确需本地复制参考时取得用户授权。不要把本仓库维护说明、语言导航或历史记录入口复制到目标。
7. 完成后检查流程适合项目、项目约束保留、无重复或冲突、保留链接有效、修改范围正确。在目标 AGENTS.md 中简短记录实际源位置及可得版本或读取日期，不虚构版本；重复采用时更新该记录。报告关键适配及理由、采用与跳过的规则、未解决的冲突、验证结果及访问或权限限制。

通用规范是自定义策略，不是官方标准。主文件只保留稳定执行规则；详细模板和解释放入按需参考文档。

## 内容入口

- [AGENTS.zh-CN.md](AGENTS.zh-CN.md)：通用规范的中文译版；英文 [AGENTS.md](AGENTS.md) 是主要维护版本，并适用于本项目的协作。
- [参考资料](references/README.zh-CN.md)：专题规则与参考资料索引，按需读取，不默认全量加载。
- [实践经验](experiences/README.zh-CN.md)：实践记录入口，积累证据、反例和待验证建议。
- [变更记录](CHANGELOG.zh-CN.md)：通用规范的重要变更及原因。

## 维护方式

1. 新经验先记录问题、场景、处理方式和观察结果，区分事实与推测。
2. 有适用边界的建议放入专题参考，不把所有经验都塞入通用规范。
3. 对可迁移、证据充分且无明显冲突的规则，提炼后合并到英文主版本 `AGENTS.md`，同步中文译文并记录变更理由。
4. 修改时检查重复、矛盾、过时能力假设和额外上下文成本；失效规则应修订或删除。

保持文档轻量。小幅措辞修正无需单独案例；未测量的 token 收益不能写成已证实结论。工具能力相关内容更新时核对当前官方资料。

## 语言维护

无语言后缀的英文文件是主版本，简体中文使用同目录下的 `.zh-CN.md` 后缀。按任务需要选择一种语言，不默认加载两种版本。

修改英文源文档时同步更新对应译文；无法同步时，标明译文尚未同步及其对应源版本。有差异时以英文为准，但不覆盖上级指令。

历史经验记录保留原语言和原哈希。语言或措辞更新不会改变旧评估所针对的版本；历史记录不证明后续版本已经过测试。
